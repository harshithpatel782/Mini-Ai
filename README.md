
# MINI-AI
### Intelligence Without Limits

MINI-AI is a personal AI assistant designed to run
on Android devices using free and open-source tools.

## Vision
Build an independent AI assistant that can:
- Answer general questions.
- Understand voice commands.
- Speak responses.
- Analyze images.
- Help with studying and coding.
- Manage permitted phone operations.
- Read and manage user-selected files.
- Remember useful information locally.
- Work offline using local AI models.

## Core Principles
1. No mandatory paid services.
2. No mandatory cloud AI API keys.
3. Local-first processing.
4. User privacy and data ownership.
5. Explicit permission for device operations.
6. Modular and maintainable architecture.

## Technology Stack
- HTML
- CSS
- JavaScript
- Python
- Flask
- SQLite
- llama.cpp
- Termux
- Android integration

## Project Structure

- web/       Frontend application
- backend/   Local server and APIs
- database/  Database and migrations
- shared/    Shared utilities and configuration
- android/   Android application
- ios/       Future iOS application
- desktop/   Future desktop applications
- assets/    Images, icons and sounds
- docs/      Technical documentation

## Security
- Never expose private credentials.
- Keep user data locally by default.
- Validate all backend requests.
- Restrict file access.
- Require explicit permission for device control.
- Do not execute arbitrary shell commands from AI output.

## Development
The project is initially developed on Android
using Termux and free development tools.
